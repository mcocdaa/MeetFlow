# AI 工作助手

这是 MeetFlow 随镜像提供的固定插件。它仅调用管理员配置的 OpenAI 兼容
`/chat/completions` 接口，生成可编辑内容；它没有工具调用能力，也不能直接写入会议、项目或行动项。

部署后以管理员身份打开“插件管理”，配置 `base_url`、`model`、`timeout_seconds` 和 API Key。
插件文件在容器启动时加载；更改启用状态后需要重启容器。生成结果会直接写入发起时的编辑器，用户可以撤销、编辑后按原有流程保存。

“整理议题记录”会由服务端按选中的议题构造上下文，其中包括可信的 `current_agenda_item`、已保存纪要、参与者、预计/实际时长、议题记录，以及自动和手动产出。上下文还会列出 `@决策:`、`@行动:`、`@开放问题:` 标签语法。生成的完整 Markdown 仅替换当前编辑器内容；插件不能直接保存会议、议题或产出，用户仍须点击“保存议题”确认落库。
