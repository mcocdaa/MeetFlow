# MeetFlow 1.0 Core Domain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v0.1 meeting package with a fresh, versioned 1.0 domain for projects, meeting series, mutable agendas, outcomes, and trustworthy meeting completion.

**Architecture:** Create focused `projects`, `meetings`, `agendas`, and `outcomes` packages behind explicit services and command endpoints. Use SQLAlchemy relationships and one new Alembic baseline. Tests create metadata directly; non-test startup migrates and refuses a legacy v0.1 database without deleting it.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, Pydantic 2, SQLite, pytest

- [ ] **Step 4: Add an explicit legacy guard**

```python
class LegacyDatabaseError(RuntimeError):
    pass

def reject_legacy_schema(engine: Engine) -> None:
    inspector = inspect(engine)
    tables = set(inspector.get_table_names())
    if "meetings" not in tables or "alembic_version" in tables:
        return
    columns = {column["name"] for column in inspector.get_columns("meetings")}
    if "project" in columns and "project_id" not in columns:
        raise LegacyDatabaseError(
            "MeetFlow v0.1 database detected; archive data/ and start fresh"
        )
```

def start(self, meeting_id: str, expected_version: int, actor: User) -> Meeting:
    meeting = self.require(meeting_id)
    require_version(meeting.version, expected_version)
    if meeting.status not in {MeetingStatus.DRAFT, MeetingStatus.READY}:

    meeting.started_at = utcnow()
    meeting.version += 1
    self.session.commit()
