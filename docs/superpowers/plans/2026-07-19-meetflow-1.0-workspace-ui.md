# MeetFlow 1.0 Workspace UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the marketing-style v0.1 interface with the approved personal workspace, project overview, and lifecycle-aware meeting workbench.

**Architecture:** Keep Vue Router and the existing fetch wrapper, but split domain types and focused page components. Persist Markdown while editing through Milkdown 7.21.3. Use optimistic versions for saves and native HTML drag events for the right-side agenda queue.

**Tech Stack:** Vue 3, TypeScript, Vue Router, Milkdown 7.21.3, DOMPurify, Vitest, Testing Library, Vite
