# 项目概览卡片对齐设计

## 背景

项目详情页的“项目状态”“下一次会议”“需要处理”“近期行动项”“近期决策”和“最近动态”使用两列 CSS Grid。当前网格设置 `align-items: start`，导致同一行的卡片按各自内容高度收缩；截图中左侧卡片明显高于右侧卡片，破坏了行对齐。

## 目标

- 桌面端同一网格行的卡片拥有一致的外框高度和底边。
- 卡片内容继续从顶部开始排列，不改变现有文案、操作入口或数据请求。
- 内容较长时由内容自然撑高整行，不使用可能造成溢出的固定高度。
- 窄屏切换为单列后，每张卡仍按自身内容高度显示。

## 方案

只调整 `frontend/src/styles.css` 中 `.project-overview-grid` 的对齐规则，将 `align-items: start` 改为 `align-items: stretch`。CSS Grid 会按每一行最高卡片确定行高，并将同一行的其他卡片拉伸到该高度；现有 `.project-dashboard-card` 的内容布局不变，因此空白区域只出现在较短卡片的底部，不会改变阅读顺序。

不采用固定 `min-height`：它需要根据断点和内容持续调参，且会在短内容卡片中制造不必要的空白。也不修改组件 DOM 结构，因为本问题只来自网格项的交叉轴对齐。

## 响应式与验证

- 保留现有 `@media (max-width: 900px)` 单列规则；单列网格每行只有一张卡，不会引入跨卡片高度绑定。
- 前端组件测试继续验证六个卡片标题和现有项目概览内容可见。
- 运行前端完整测试与生产构建，并在本地 Docker 页面确认桌面两列的卡片底边对齐。

## 非目标

本次不修改后端接口、数据库、卡片内容、间距体系、移动端布局或 Docker 配置。
